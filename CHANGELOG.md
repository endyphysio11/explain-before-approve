# Changelog

All notable changes to Explain Before Approve are documented here.

## [0.1.0] - 2026-08-14

### Added

- Provider-independent Explain Before Approve Agent Skill.
- Standard-library Python analyzer for Git, filesystem, package, database, and secret actions.
- Four-level risk model and three human-decision recommendations.
- Compound-action parsing with highest-risk primary-domain selection.
- Safety tests proving candidate strings remain inert data.
- Labeled fixture corpus, quantitative acceptance checks, and qualitative evaluation rubric.
- Open-source documentation and MIT license.
